# International Lisp Conference (ILC) 2002

ILC 2002 was held on October 27-31, 2002 in San Francisco, California, USA.

The conference website `www.international-lisp-conference.org` 
no longer exists, but
[it can be visited via the Wayback Machine](https://web.archive.org/web/20021128232744/http://international-lisp-conference.org/)
at the
[Internet Archive](https://archive.org).
