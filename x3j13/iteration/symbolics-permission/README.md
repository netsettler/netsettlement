# Release of Symbolics rights on ANSI LOOP facility

## Structure of this folder

This folder contains a packet of information that includes:

* A cover letter addressed from Gary Roberts at Symbolics to Glenn
  Burke at Apple Computer saying that Symbolics had "decided to
  release the right to use a portion of its LISP system, known
  informally as 'ANSI LOOP facility,' so that others in the LISP
  community may use it."

* Seven attachments, which are pieces of code covered by the release.

I separated out the attachments into separate files here. I tried to
name the files in a way that makes their relations, order, role, and
identity clear.

## Additional useful context

It's interesting that all the files have the same version, but that's
probably because this was, as the letter indicates, a snapshot. They
were probably copied from elsewhere. Their file creation dates (shown
in the running heads of each of the included files) are likewise all
the same.

Gary didn't identify his title in the letter, but I seem to recall him
being Director of Marketing, or something like that.

Note that in ordinary daily tool use within Symbolics, the file server
named `Stony-Brook.SCRC.Symbolics.COM` was referred to by its
"short name" `S`. The running heads on each of these files uses
that short name, while the cover letter spells it out. But
`S:>something>`
and
`STONY-BROOK.SCRC.Symbolics.COM:>something>`
refer to the same
`>something>`,
so there was no ambiguity about which files were referred to. And,
anyway, Gary included attachments containing the text content of the
files he was referring to, so that would presumably make the actual
file names unlikely to be important from a legal standpoint and mainly
a useful bit of contemporary provenance.

There is some record of the interchanges that led to the writing of this
letter contained in 
[the Correspondence folder](Correspondence/README.md)
within this folder.

There was a prior draft of this letter that was marked up for changes in
[the Drafts folder](Drafts/README.md)
within this folder.

Gary names me as the person to ask questions of, which is probably
