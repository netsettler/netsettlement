# Correspondence about LOOP iteration macro permissions

This folder contains some documents that went back and forth trying
to get permissions sorted so that the community could use a common
implementation of the LOOP macro as the basis of their work.

I'm pretty sure this correspondence is not complete, but it has a
substantial amount of what went back and forth behind the scenes
culminating in the permission letter from Gary Roberts at Symbolics on
1992-02-03. (See [the parent folder's `README.md`](../README.md) for
more detail on that letter.)

 --Kent Pitman 26-Nov-2026
