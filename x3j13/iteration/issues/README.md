# Issues related to Iteration

This directory is primarily for issue writeups relate to the iteration
facilities, although sometimes we received requests that were in
other, less formal, formats. 

 * `1988-06-14_letter_from_Richard_Waters_about_pretty-printer_needs.pdf`
 * `1989-03-23_Scott_Cyphers_CLOS_problems.pdf`

I can't say for sure whether these items were acted upon. We were
tracking everything on paper, and there was a vast quantity of it, so
sometimes things got lost. But I record it in this historical record
anyway, just so that if something did get lost before, maybe it will
be found in the future. I don't have time as I construct this archive
to test such matters.\
