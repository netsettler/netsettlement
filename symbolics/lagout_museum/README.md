# The Lagout Museum

In checking whether some files I had physical copies of were already archived,
I discovered there had once been a site called "The Lagout Museum" (`lagout.org`)
that had gone offline, taking with it a lot of history.

Fortunately, the data was possible to find by using
[The Wayback Machine at archive.org](https://archive.org).

_Unfortunately_, the indexing was pretty poor and you could only find it easily
if you knew what you were looking for.

_Also unfortunately_, it's a bit tedious to browse
[the Wayback Machine's directory tree](https://web.archive.org/web/20251010122927/https://doc.lagout.org/science/0_Computer%20Science/0_Computer%20History/old-hardware/symbolics/)
because the ghost of the Lagout Museum, now frozen in archived Javascript,
asks for donations&dagger; via a pop-up at just about every step.

So what I have done here, rather than create duplicates of what's already
available on the Wayback Machine, is to create a mirror of the Lagout Museum's
Symbolics-related directory structure that can be more easily browsed.
Each remote Lagout Museum directory is matched in this mirror by a `WAYBACK.md` file.
These files are the branch points of the mirrored tree.
The leaf nodes, the actual files, are stored at the Wayback Machine itself.
